# 판과 기물 아트 기준

배경 그림·캐릭터·풍경 없이 장기판 자체가 중심이다. 서브컬처 느낌은 옻칠색 금속 판, 청록·홍색 궁성 구획과 상감 문양, 금색 테두리, 은색/황동색 팔각 기물에 적용한다. 작은 문양은 외곽에 두어 교차점과 이동 표시를 가리지 않는다. 카메라는 정면 직교이며 한자 기물은 각 진영을 향한다.

3D 모델은 tools/models.mjs, 한자와 판 텍스처는 tools/textures.py, 엔진 HUD 프레임은 tools/project.mjs로 직접 작성한다. Windows 맑은 고딕의 래스터 결과만 사용하며 글꼴 파일은 배포하지 않는다. 캐릭터 일러스트와 관련 모델은 제거했다.
