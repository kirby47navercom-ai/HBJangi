# 아트 기준

사용자 기준: 우주 배경 제거, 기울이지 않은 정면 3D 판, 상대 기물은 상대 쪽으로 향하는 한자, 서브컬처 게임의 대국 HUD. 웹 카드형 사이드바 없음.

3D 모델은 `tools/models.mjs`, 기물의 한자와 판 텍스처는 `tools/textures.py`, HUD 프레임은 `tools/project.mjs`로 작성했다. 글꼴은 설치된 Windows 맑은 고딕의 래스터 결과만 사용하고 글꼴 파일을 배포하지 않는다.

캐릭터 일러스트: 내장 ImageGen 도구. 최종 파일 `Assets/Art/Duel.png`. 원본 생성 결과를 프로젝트에 복사해 사용했다. UI/기물/판은 이 이미지에 구워 넣지 않고 실제 엔진에서 그린다. 일러스트는 장식이며 캐릭터 AI나 스토리 기능은 없다.

Warm studio daylight, refined parchment ivory, lacquer charcoal, dusty jade and muted burgundy palette. Premium elegant 2D anime game key art. NO space, NO stars, NO nebula, NO sci-fi, NO board, NO game pieces, NO interface, NO text, NO lettering, NO badges, NO rounded cards. Must keep the center clear and low detail, art mostly along the edges. Do not put people in center. Original characters, not any existing franchise.
